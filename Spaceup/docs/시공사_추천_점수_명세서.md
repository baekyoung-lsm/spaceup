# 시공사 추천 점수 - 백엔드 반영 명세

> 원본: `시공사 추천 점수 구성.txt`. 이 문서는 그 내용을 반영하면서 **실제로 바뀐/추가된 부분만** 정리합니다.
> 테스트 완료: 2026-07-27, 실제 API 호출로 계산값 검증됨.

## 1. 매칭 점수 계산 로직 교체

`RuleBasedMatchingScoreCalculator`가 기존 "활동지역+전문분야 일치도" 방식에서 **리뷰(40) + 예상 견적 적합도(35) + 일정 적합도(25) = 100점** 방식으로 완전히 바뀌었습니다.

```
매칭 점수 = 리뷰 점수 + 견적 점수 + 일정 점수 (최대 100점)
```

### 리뷰 점수 (최대 40점)
- 평점 점수(최대 32점) = `평점 ÷ 5 × 32`
- 리뷰개수 점수(최대 8점): 100개↑ 8점 / 50~99개 6점 / 20~49개 4점 / 10~19개 2점 / 1~9개 1점 / 0개 0점

### 예상 견적 적합도 (최대 35점)
- 사용자 예상 견적(`QuoteRequest.budgetMax`, 없으면 `budget`)이 시공사 견적 범위(`estimateMin`~`estimateMax`) 안이면 35점
- 범위를 벗어나면 차이율(`|벗어난 금액| ÷ 사용자 예상 견적 × 100`)에 따라: 10% 이내 28점 / 20% 이내 20점 / 30% 이내 10점 / 초과 0점

### 일정 적합도 (최대 25점)
- 시공사의 가장 빠른 가능일(`availableFromDate`)이 임대인 희망일(`QuoteRequest.desiredDate`)보다:
  - 이전이거나 당일: 25점 / 7일 이내 늦음: 20점 / 14일 이내: 15점 / 30일 이내: 8점 / 그 이상: 0점

### 변경 전과의 차이
- 프로필이 없는 시공사의 점수가 **기본 참여점수 20점 → 0점**으로 바뀌었습니다(새 공식엔 "기본 점수" 개념이 없음).
- 지역/전문분야 일치 여부는 더 이상 점수에 반영되지 않습니다.

## 2. 엔티티 변경 - `ContractorProfile`

신규 컬럼 4개 추가 (테이블: `contractor_profiles`):

| Java 필드 | DB 컬럼 | 타입 | 설명 |
|---|---|---|---|
| `reviewCount` | `review_count` | int, nullable | 리뷰 개수 (아직 리뷰 도메인 없어 수동 갱신) |
| `estimateMin` | `estimate_min` | bigint, nullable | 시공사가 통상 제시하는 견적 하한 |
| `estimateMax` | `estimate_max` | bigint, nullable | 시공사가 통상 제시하는 견적 상한 |
| `availableFromDate` | `available_from_date` | date, nullable | 가장 빠른 시공 가능일 |

기존 `rating`(평점)은 그대로 있고, `updateRating(double)` → `updateRating(double newRating, int reviewCount)`로 시그니처가 바뀌었습니다(평점+리뷰개수를 한 번에 갱신).

## 3. 신규/변경 API

### `PUT /api/contractors/me/service-info` (신규)
시공사가 본인의 견적 범위/가능일을 등록. 인증 필요(시공사 본인).

요청:
```json
{
  "estimateMin": 50000000,
  "estimateMax": 80000000,
  "availableFromDate": "2026-08-01"
}
```
응답: `{ "success": true, "message": "견적 범위/가능 일정이 저장되었습니다.", "data": null }`

### `GET /api/requests/{requestId}/recommended-contractors` (신규)
해당 의뢰에 대해 상담 가능(`availableForConsult=true`)한 시공사 전체의 매칭 점수를 계산해, **점수 높은 순 상위 3개**를 반환. 인증 필요.

응답 예시:
```json
{
  "success": true,
  "message": "추천 시공사 조회 완료",
  "data": [
    {
      "contractorId": 7,
      "companyName": "GoodContractor",
      "rating": 0.0,
      "reviewCount": 0,
      "estimateMin": 50000000,
      "estimateMax": 80000000,
      "availableDate": "2026-08-01",
      "matchScore": 60
    }
  ]
}
```

### `GET /api/contractors/me`, `PUT /api/contractors/me` 응답 변경
`ContractorProfileResponse`에 `reviewCount`, `estimateMin`, `estimateMax`, `availableFromDate` 필드가 추가되었습니다(기존 필드는 그대로).
